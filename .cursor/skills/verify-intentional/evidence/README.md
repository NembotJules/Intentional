# Evidence Directory

This directory holds verification artifacts from live user-path tests:
- Screenshots (before/after actions)
- HAR files (network activity)
- Console logs
- DOM snapshots
- Playwright traces

**Gitignored contents**: All files except this README are excluded from version control. Evidence is session-local and should not be committed.

## Retention
Evidence files persist after cleanup to allow post-run inspection. Delete manually when no longer needed.
